# Лабораторная работа №1

Android-приложение по заданию из архива: имя и фамилия, номер группы, картинка по центру и две кнопки, которые скрывают и снова показывают эти элементы.

Имя и группа задаются в `app/src/main/res/values/strings.xml`:

- `student_name` — имя и фамилия, серый текст в левом нижнем углу
- `group_name` — группа, красный текст в правом верхнем углу

## Что есть на экране

- «Кирилл Волошенко» — левый нижний угол, серый цвет
- «Т-433901-ИСТ» — правый верхний угол, красный цвет
- `btr.png` из задания — по центру
- кнопка «Скрыть надписи» / «Показать надписи» — прячет и возвращает имя и группу
- кнопка с иконкой из `inv.svg` — прячет и возвращает картинку по центру

Исходный SVG лежит в `app/src/main/assets/inv.svg`. На кнопке используется тот же рисунок в формате Vector Drawable: `app/src/main/res/drawable/ic_inv.xml`. Так Android рисует SVG-иконку без дополнительных библиотек.

## Как открыть

Нужны Android Studio и JDK 17.

1. Откройте эту папку как проект.
2. Дождитесь синхронизации Gradle.
3. Если Android Studio спросит SDK, укажите установленный Android SDK. Файл `local.properties` создастся сам.

## Эмулятор

1. В Device Manager создайте виртуальное устройство, например Pixel с образом Android 14 или новее.
2. Запустите его.
3. Нажмите Run у конфигурации `app`.

## Физическое устройство

1. На телефоне включите режим разработчика и отладку по USB.
2. Подключите телефон кабелем и разрешите отладку.
3. Выберите устройство в списке Android Studio и нажмите Run.

Собрать APK из командной строки:

```bash
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Его можно скопировать на телефон и установить вручную.
